# Mongoose plugins 1.1.2

Release date: 2026-11-07. Application-support changes: PR #53, merge `d594de5`, head `df4b082`.
Requires Java 21. The reactor now pins Mongoose 1.1.3 and Fluxtion runtime 1.1.4.

## New application helpers

- `PersistentNode` and `Seed` in `svc-cache` save node state with its delivery position at delivery completion.
- `StateJson` in `lib-jsonserialiser` supplies shared JSON serialization.
- `LineMapper`, `Rejected` and `JsonLineSink` in `connector-file` support line-based input and output.
- `FixtureRunner` in `mongoose-test-support` supports deterministic application tests.
- Generated configuration schemas and their reference documentation now describe Mongoose 1.1.3.

## Upgrade notes

Use Mongoose 1.1.3 with these plugins. Its file feeds default to PAUSE and COMMITED pointers advance after processing.
Outputs remain at-least-once after a crash: external effects are not transactional with saved node state.
`PersistentNode` guards state against positioned redelivery in supported generated/interpreted processors. Use one
persistent node per processor, or independent nodes: writes across nodes are not atomic. Handwritten adapters that
retry partial mutations are unsupported. A quarantined supported processor must be restarted after fixing its cause.
Unpositioned events retain per-cycle saves. See the [cache guide](../../service/svc-cache/README.md) for the full contract.

## JsonFileCache behaviour changes

- Cache-write logging moves from INFO to DEBUG and reports key counts rather than key names.
- JSON files are compact; older pretty-printed files still load.
- Writes replace the file atomically where supported. A symlink is replaced rather than its target being written;
  existing ownership and permissions are not preserved. POSIX temporary files are owner-only.
- Only an unsupported atomic move falls back to a normal replacing move. Other filesystem failures propagate and
  keep the cache dirty for retry. Windows behaviour has not been tested.
- Each write uses a uniquely named sibling temporary file. Initialization cleans only exact matching stale files
  and refuses reserved temporary-file names, control characters and names exceeding 229 UTF-8 bytes.
- Teardown does not write after failed initialization. Process-kill durability does not guarantee power-loss durability.

Existing application-local helper classes should migrate to the public packages described in each module README;
do not retain duplicate implementations with different persistence semantics.
