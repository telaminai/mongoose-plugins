# Mongoose plugins 1.1.3

Release date: 2026-11-08. Requires Java 21. Runs on Mongoose 1.1.3 and Fluxtion runtime 1.1.4; the BOM remains 1.0.80.

## Changes

- PR #55, merge `7f39a8d`: generated configuration schemas no longer offer setters inherited only as empty
  interface defaults. For example, services no longer advertise a `feedStatusEvents` setting that does nothing.
- PR #56, merge `fb7d01e`, head `f4bc568`: `PersistentNode` supports explicitly declared feed renames through
  `renamedFrom(String feed)`. A saved position transfers only when the source epoch matches. If the old feed name
  also delivers in the same run, before or after the transfer, the node throws `IllegalStateException`.

## Upgrade notes

No action is needed unless a feed is renamed. To preserve its saved position, override `renamedFrom` in the
`PersistentNode` subclass and stop the old feed before restarting. Without a declaration, behaviour is unchanged.
The transfer requires a matching non-zero source epoch. Mongoose's file source supplies one; other current sources
without an epoch cannot use this transfer. Keep the declaration through the recovery window after a rename.

Epoch equality alone is not permission to rename. An old feed still running in a later run after the transfer
was saved cannot be detected by this same-run guard. Outputs remain at-least-once after a crash.
See [A declared feed rename in the cache guide](https://github.com/telaminai/mongoose-plugins/blob/v1.1.3/service/svc-cache/README.md)
for the ownership and recovery contract.
