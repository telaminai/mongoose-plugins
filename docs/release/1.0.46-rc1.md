# mongoose-plugins 1.0.46-rc1

Pre-release candidate for **Mongoose 1.0.33-rc1**, with **Fluxtion runtime 1.1.2**.
Publication is subject to exact-commit qualification and merge approval. This is not client migration clearance.

- Admin REST now parses JSON bodies, returns 400 for invalid input, 404 for unknown commands and 503 when the
  registry is unavailable, with one reply per request (#40).
- Admin web validates command/login bodies and accepts `arguments` as well as `args` (#41).
- File, Chronicle, Aeron and multicast connectors notify the publisher when startup completes. Startup events
  replay once; subsequent live traffic no longer grows the startup event log by default. Applications that need
  lifetime retention must explicitly configure and size it; startup caching is not a durable event journal.
- Schema metadata includes the new core settings. All modules must be rebuilt against this RC.

Capture importers, dashboards, pruning and custom capture plugins need the migration checks documented in the
[Mongoose release notes](https://github.com/telaminai/mongoose/blob/feature/control-plane/docs/release/release-notes-1.0.33-rc1.md)
and [client checklist](https://github.com/telaminai/mongoose/blob/feature/control-plane/docs/release/client-migration-1.0.33.md).

## Publication

The RC workflow is an explicit adaptation of the existing Repsy release pipeline: push the approved annotated
`v1.0.46-rc1` tag on the exact qualified commit after Mongoose is published and resolvable. It deploys that POM
version with Java 21 using the existing Repsy repository and secret names, without Maven release preparation or
automatic branch merges. Each PR merge and the publishing adaptation require owner approval. Never push this RC
to the legacy `release` branch. Qualification includes the full reactor, schema gate and dependency tree; release
evidence is retained separately so it does not change the tagged candidate SHA.

After publication, resolve all module artifacts in a clean Maven repository, then create a GitHub pre-release
with the notes, candidate SHA and evidence. **Released as a pre-release; not cleared for client migration.**
