# mongoose-plugins 1.0.46

Stable release for **Mongoose 1.0.33**, Fluxtion runtime **1.1.3**, BOM **1.0.80**.
The runtime Java source is unchanged from the qualified and published 1.0.46-rc1.
Release qualification does not clear client migration.

- Admin REST now parses JSON bodies, returns 400 for invalid input, 404 for unknown commands and 503 when the
  registry is unavailable, with one reply per request (#40).
- Admin web validates command/login bodies and accepts `arguments` as well as `args` (#41).
- File, Chronicle, Aeron and multicast connectors notify the publisher when startup completes. Startup events
  replay once; subsequent live traffic no longer grows the startup event log by default. Applications that need
  lifetime retention must explicitly configure and size it; startup caching is not a durable event journal.
- Schema metadata includes the new core settings. All modules must be rebuilt against this RC.

Capture importers, dashboards, pruning and custom capture plugins need the migration checks documented in the
[Mongoose release notes](https://github.com/telaminai/mongoose/blob/v1.0.33/docs/release/release-notes-1.0.33.md)
and [client checklist](https://github.com/telaminai/mongoose/blob/v1.0.33/docs/release/client-migration-1.0.33.md).
