# Mongoose plugins 1.1.4

Requires Java 21, Mongoose 1.1.4 and Fluxtion runtime 1.1.4; the BOM remains 1.0.80.

Chronicle usage analytics is excluded from the shared Mongoose dependency and the Chronicle Queue and Map connector dependencies. An enforcer rule prevents reintroduction. Mongoose 1.1.4 also disables analytics before queue use unless the application explicitly sets the property.

Current configuration schemas, their golden fixture and the reference documentation now describe Mongoose 1.1.4. Historical versioned schemas remain unchanged.

Published to the Fluxtion public Repsy repository: https://repo.repsy.io/mvn/fluxtion/fluxtion-public. No Maven Central publication is part of this release.
